# Out-of-scope knowledge base

Rejected or deferred requests, with reasons — written by triage so the same thing isn't re-litigated. One file per theme, append entries with date and the deciding reason.

Current known out-of-scope themes (from `docs/spec.md`):

- Astro < 7 / Vite < 8 / zod 3 support (new-projects philosophy)
- SCSS, Tailwind class emission, WYSIWYG/block editing, drag-drop layout
- Content sources beyond Content Collections (`.ts` data files, DB/CMS)
- Any git operations performed by the product itself
- Production-build presence of any kind
